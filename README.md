## 📋 نظرة عامة

**لمسة (LAMSA)** هو متجر إلكتروني فاخر متخصص في:
- 🧴 **العناية بالبشرة** - منتجات أصلية ومختارة بعناية
- 💇 **العناية بالشعر** - روتين كامل لشعر صحي
- 🌹 **العطور اليدوية** - تركيبات حصرية مصنوعة خصيصاً
- 🎁 **الهدايا الفاخرة** - تنسيق احترافي للمناسبات
- 💍 **الإكسسوارات** - مجوهرات وإكسسوارات أنيقة
- ⚡ **أجهزة التجميل** - أحدث التقنيات

## ✨ الميزات الفريدة

### 🎯 تجربة تفاعلية ذكية

#### 1. **اختارلي روتين** 🔥
نظام ذكي يسألك 4 أسئلة بسيطة ويقترح روتين عناية مخصص تماماً لـ:
- نوع بشرتك
- نوع شعرك
- مشاكلك الرئيسية
- ميزانيتك

#### 2. **صمم هديتك** 🎁
اختر:
- المناسبة (عيد ميلاد، خطوبة، زفاف...)
- المستلم (أم، زوجة، صديقة...)
- الميزانية
**وسنقوم بتنسيق هدية فاخرة مع تغليف راقي!**

#### 3. **اعمل برفانك** 🌹
صمم عطرك الخاص! اختر:
- العائلة العطرية (عود، مسك، زهري...)
- التركيز (EDT, EDP, Extrait)
- الحجم والمكونات الإضافية
**ونصنعه لك بحرفية يدوية!**

## 🚀 كيفية التشغيل

### الطريقة الأولى (مباشرة):
1. افتح ملف `index.html` في أي متصفح
2. ابدأ التصفح!

### الطريقة الثانية (Local Server):
```bash
# استخدم Python
python -m http.server 8000

# أو استخدم Node.js
npx http-server

# ثم افتح
http://localhost:8000
```
